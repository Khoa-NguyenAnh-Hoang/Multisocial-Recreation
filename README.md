# Multisocial-Recreation

DS319 - Large Language Models

Multilingual stereotype/hate speech classification across Arabic, English, Vietnamese, and Chinese.

## Contents

| Notebook | Description |
|---|---|
| `00_data_prep.ipynb` | Dataset preparation |
| `01_pretrained.ipynb` | Zero-shot / pretrained baselines |
| `02_finetuning.ipynb` | Fine-tuning XLM-R |
| `03_statistical.ipynb` | Statistical baselines |
| `04_transfer.ipynb` | Cross-lingual transfer experiments |
| `generate_multisocial_{ar,en,vi,zh}.ipynb` | Data generation by language |

## Data

Generated synthetic multilingual hate speech dataset in `multisocial_outupts/`.
Model outputs, metrics, and figures are also under `multisocial_outupts/`.
